# ✅ To-Do List Web Application

A responsive and interactive To-Do List application built using HTML, CSS, and JavaScript. It helps users organize daily tasks, track progress, and manage their activities efficiently.

## 🚀 Live Demo

[🌐 Click Here to Use To-Do App](https://ajeet497.github.io/TO_DO_WEB/)

## ✨ Features

- Add, edit, and delete tasks
- Mark tasks as completed or active
- Organize tasks using categories
- Filter tasks by All, Active, and Completed
- Clear completed tasks
- Dynamic task counters
- Persistent storage using Local Storage
- Motivational quotes
- Responsive design for mobile and desktop
- Android app support using Capacitor

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Local Storage
- Capacitor
- Android Studio

## 📱 Android Support

The application supports Android integration using Capacitor, allowing the web application to be packaged as an Android app.

## 💻 Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/ajeet497/TO_DO_WEB.git
   ```

2. Navigate to the project folder:

   ```bash
   cd TO_DO_WEB
   ```

3. Open `index.html` in your browser.
